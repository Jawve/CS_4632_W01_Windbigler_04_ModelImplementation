This is a very simple mouse macro, which has basic mouse movement controls for my simulation assignment.

KEY NOTES:

if you are using the playback feature, to stop use A+S to stop the events.
This is an exe for convention sake, I packaged everything into one install located in dist. 
This should be the only thing you have to download, if you want to view the raw file, there is the py file available for download.


TO USE:
users will be able to click on a function, such as click up, down, wait, etc and a prompt will appear. Users will be able to modify these parameters.
For click events, a red box will show up where the event will take place. Once a user is done with a event, they can continue to add to the field, or delete if needed.
